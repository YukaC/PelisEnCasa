# Security Policy

## Supported versions

| Version   | Supported |
| --------- | --------- |
| `master`  | Yes       |

This repository’s default branch is `master` (not `main`).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report privately via:

- [GitHub private security advisory](https://github.com/YukaC/PelisEnCasa/security/advisories/new) for this repository, or
- Email: **agusyuk25@gmail.com**

Include steps to reproduce and impact if known. We aim to acknowledge reports within a few business days.

## Scope

Student project: Flask API with in-memory/session login and a JSON file database. Reports about missing authentication on admin routes, unsafe file upload paths, or CORS misconfiguration are in scope. This is not a production service; severity expectations should reflect demo/educational use.
